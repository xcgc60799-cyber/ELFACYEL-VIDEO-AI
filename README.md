# ELFACYEL VIDEO AI 🇩🇿🖤

**Free Music Video Studio** — Version 1.0  
Application Web & Android (PWA) hébergée sur GitHub Pages, conçue pour créer des clips musicaux synchronisés avec le rythme sans aucun abonnement ni API payante.

## Fonctionnalités V1.0
- **Dashboard** : Suivi en temps réel des projets et scènes.
- **Project Manager** : Gestion des formats (16:9, 9:16, 1:1).
- **Character Lock** : Sauvegarde locale de l'identité visuelle de l'artiste.
- **Scene Director** : Montage multi-scènes avec durées personnalisées.
- **Music Sync** : Analyse fréquentielle Web Audio API (détection des basses).
- **Video Editor & Export** : Rendu temps réel avec effets réactifs et export `.webm`.
